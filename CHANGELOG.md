# Changelog

## 0.1.0

Initial industrial Furnace implementation for Minecraft 1.21.1 and NeoForge.
Three HE-only tiers, persistent parallel SMELTING jobs, dedicated physical ports,
HomeCore device integration, official HomeLink UI Kit, XP collection and optional
recipe viewers. See `docs/VALIDATION.md` for executed checks and limits.

Visual revision: distinct compact, wide and tall cabinets; continuous multiblock
chambers; recessed glass, doors, handles, feet and physical port fittings;
sixteen 64 x 64 textures; tier-specific glowing resistance bars and aligned
front fans. Rendering bounds now cover the whole multiblock. Resource tests
validate model geometry, UVs, parent chains and decoded PNG references.
